# POST 問卷題目重整設計

## 目標

保留既有 PRE 問卷、課程設定、教師／學生基本資料分流、登入信箱、選填聯絡信箱及重複填答覆蓋機制，只將 POST 問卷改成新興科技研習回饋題目。

## POST 題目結構

### P－教學法與活動設計

以下四題皆為必填五點量表，1 代表「非常不同意」，5 代表「非常同意」。

1. 講師的說明清楚、容易理解。
2. 教學方式能引起我的注意與參與。
3. 活動、示範或討論有助於理解內容。
4. 課程時間與進度安排合適。

### C－課程內容

以下四題皆為必填五點量表。

1. 本次主題符合我的需求或興趣。
2. 課程內容充實且難度適當。
3. 課程內容具有實用性。
4. 我希望繼續了解相關主題。

### K－新興科技知識與收穫

以下四題皆為必填五點量表。

1. 我對本次介紹的新興科技有更深入的認識。
2. 我能說明這項新興科技的基本概念或用途。
3. 我能辨識新興科技可能帶來的機會與風險。
4. 我願意把所學應用在學習、教學或生活中。

### 教師專屬題目

教師選擇身份後顯示以下兩題，皆為必填五點量表。

1. 內容對我的教學或專業成長有幫助。
2. 我有信心把所學運用在課堂或工作中。

### 學生專屬題目

學生選擇身份後顯示以下兩題，皆為必填五點量表。

1. 活動方式能幫助我理解內容。
2. 課程難度適合我。

### 未來主題

教師與學生皆顯示「希望未來增加哪些主題？」。此題選填且可複選：生成式 AI、AR/VR、物聯網、機器人、資安。另提供選填的「其他」文字欄位。

### 學習收穫與建議

以下三題皆為選填文字題。

1. 今天最有收穫的內容是什麼？
2. 有哪些地方可以改進？
3. 還想參加哪些主題？

## 資料欄位

- 保留既有 `Q1` 至 `Q8` 欄位及所有歷史回覆。
- 新增 `P1` 至 `P4`、`C1` 至 `C4`、`K1` 至 `K4`。
- 教師與學生專屬量表共用 `R1`、`R2`，由同列的身份欄位判讀題意。
- 新增 `未來主題`，以穩定分隔符號保存多個選項。
- 新增 `其他主題`，保存使用者輸入的其他主題。
- 新增 `收穫內容`、`改進建議`、`想參加主題`。
- POST 新回覆只寫入新欄位；PRE 維持既有 `Q1` 至 `Q8` 寫入規則。

## 遷移與覆蓋

- 啟動或提交時檢查標題列，僅補上缺少的新欄位。
- 已存在的新欄位不得重複插入。
- 既有資料列不得刪除、重排或清空。
- 唯一鍵維持「登入信箱＋課程代碼＋階段」，同一填答者可修正 POST 回覆。

## 驗證

- 前端只在 POST 顯示新題目；PRE 題目與驗證不變。
- 12 題共通量表及 2 題身份專屬量表均須填 1 至 5。
- 未來主題及三題文字回饋允許空白。
- 教師不送出學生題目，學生不送出教師題目。
- 後端拒絕偽造角色、不合法量表值及未列出的複選項目。
- 測試須涵蓋 PRE 回歸、教師 POST、學生 POST、選填空白、複選其他、資料遷移及覆蓋更新。
